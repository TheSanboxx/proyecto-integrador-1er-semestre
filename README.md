# Proyecto Integrador — 1er Semestre (Ingeniería de Datos e IA)

**Autores:** Daniel C. & Santiago B.  
**Institución:** Universidad Santo Tomás — Seccional Tunja (2026-2)  
**Pregunta guía:** *¿Cómo afecta el tiempo diario de uso de dispositivos móviles al nivel de estrés y al desempeño académico de los jóvenes?*

## Estructura del Proyecto

```text
proyecto-integrador-1er-semestre/
├── app.py                            # Aplicación completa en Streamlit (un solo archivo)
├── README.md                         # Guía rápida de instalación y ejecución
├── requirements.txt                  # Dependencias (streamlit, pandas, numpy, matplotlib)
├── Proyecto_1__Semestre_3_en05.ipynb # Notebook de exploración inicial en Colab
└── data/
    └── Smartphone_Usage_And_Addiction_Analysis_7500_Rows.csv  # Dataset (7.500 filas)
```

## Cómo ejecutar la aplicación

1. Abrir una terminal en la carpeta `proyecto-integrador-1er-semestre/`.
2. Instalar dependencias (si aún no están instaladas):
   ```bash
   pip install -r requirements.txt
   ```
3. Ejecutar Streamlit:
   ```bash
   streamlit run app.py
   ```
